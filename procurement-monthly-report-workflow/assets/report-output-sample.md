# 月度药品销售动销分析报告
呈报对象：采购总监
呈报部门：采购部
数据周期：本月度（同比基期为去年同期）

## 一、品种动销分析
### （一）销售量 TOP10 品种及增长说明
本月销售量排名前 10 的品种及同比表现如下：
- 广药集团 - 板蓝根颗粒：450.0 万盒，同比 + 18.4%，增长原因：换季呼吸道疾病防控需求提升，终端备货量增加
- 石药集团 - 布洛芬缓释胶囊：320.0 万盒，同比 + 77.3%，增长原因：解热镇痛类日常储备需求稳定上升，临床认可度高
- 哈药集团 - 葡萄糖酸钙口服液：280.5 万盒，同比 + 47.6%，增长原因：育儿群体补钙需求增长，终端动销政策拉动明显
- 石药集团 - 二甲双胍片：210.8 万盒，同比 + 2.6%，增长原因：慢病用药刚性需求稳定
- 云南白药 - 云南白药气雾剂：195.0 万盒，同比 + 21.9%，增长原因：运动损伤、日常跌打护理需求提升，品牌效应拉动
- 扬子江药业 - 苏黄止咳胶囊：180.2 万盒，同比 + 28.3%，增长原因：呼吸道止咳类用药临床推荐率高，患者复购率高
- 华北制药 - 阿莫西林胶囊：150.5 万盒，同比 + 25.4%，增长原因：抗生素类基础用药需求稳定，集采中标后覆盖渠道拓宽
- 同仁堂 - 六味地黄丸：140.5 万盒，同比 + 8.1%，增长原因：慢病调理需求增长，国潮品牌认可度提升
- 广药集团 - 小柴胡颗粒：130.0 万盒，同比 - 3.7%，属于小幅正常波动
- 修正药业 - 肺宁颗粒：110.0 万盒，同比 + 22.2%，增长原因：清肺类产品健康科普带动需求上升

### （二）销售量倒数 10 品种及滞销风险分析
本月销售量排名倒数 10 的品种及同比表现如下：
- 同仁堂 - 感冒清热颗粒：100.0 万盒，同比 - 4.8%
- 扬子江药业 - 蓝芩口服液：90.0 万盒，同比 - 40.0%
- 华北制药 - 头孢拉定胶囊：85.2 万盒，同比 - 10.3%
- 哈药集团 - 双黄连口服液：85.0 万盒，同比 - 43.3%
- 以岭药业 - 连花清瘟胶囊：80.0 万盒，同比 - 68.0%
- 云南白药 - 蒲地蓝消炎片：75.0 万盒，同比 - 31.8%
- 修正药业 - 斯达舒胶囊：60.5 万盒，同比 - 28.8%
- 以岭药业 - 参松养心胶囊：55.0 万盒，同比 + 14.6%
- 石药集团 - 阿奇霉素片：45.5 万盒，同比 - 24.4%
- 齐鲁制药 - 安立生坦片：35.0 万盒，同比 + 75.0%

滞销原因汇总：
1. 疫情相关用药（连花清瘟、双黄连）需求退潮，销量大幅下滑；
2. 呼吸道类用药（蓝芩、蒲地蓝）市场竞争加剧，需求向高性价比品种转移；
3. 抗生素类（头孢拉定、阿奇霉素）集采后竞品价格优势更明显，需求分流；
4. 消化类用药（斯达舒）产品迭代，消费者选择转移；
5. 专科用药（安立生坦）受众群体窄，销量基数低。

风险提示：上述下滑品种存在库存积压、资金周转效率降低的风险，需重点监控库存水平。

## 二、供应商表现分析
### （一）核心优质供应商
- 销量最高供应商：广药集团，整体销量 580.0 万盒，核心品种板蓝根颗粒贡献主要销量，渠道覆盖能力强
- 毛利贡献最高供应商：石药集团，整体毛利额 464.5 万元，布洛芬、二甲双胍双品种拉动毛利增长

利润奶牛供应商（毛利贡献高且稳定性强）：
- 哈药集团：单品种葡萄糖酸钙口服液毛利达 392.7 万元，毛利贡献占比超 15%，盈利性极强
- 云南白药：单品种气雾剂毛利达 351.0 万元，品牌溢价能力突出，毛利稳定
- 石药集团：整体毛利规模第一，品种结构均衡，抗风险能力强

### （二）重点风险供应商
以岭药业为核心风险供应商：核心品种连花清瘟胶囊销量同比暴跌 68%，整体销量较去年同期下滑 45.3%，整体毛利贡献仅 174 万元，存在库存积压、动销不足的高风险。

## 三、量利综合象限核心分析
### （一）量利双高金牛品种（重点表扬）
符合销量大、毛利额高的核心品种如下：哈药集团葡萄糖酸钙口服液（销量 280.5 万盒 / 毛利 392.7 万元）、云南白药气雾剂（195.0 万盒 / 351.0 万元）、石药集团布洛芬缓释胶囊（320.0 万盒 / 256.0 万元）、广药集团板蓝根颗粒（450.0 万盒 / 225.0 万元）、扬子江药业苏黄止咳胶囊（180.2 万盒 / 216.2 万元）、同仁堂六味地黄丸（140.5 万盒 / 210.8 万元）。

上述品种为公司核心盈利支柱，建议优先保障备货、争取供应商政策支持。

### （二）高销量低毛利品种（公司搬运工）
典型品种为广药集团板蓝根颗粒（单盒毛利 0.5 元）、石药集团二甲双胍片（单盒毛利 0.6 元）：
原因分析：均为民生类 / 慢病集采品种，定价受政策管控，成本接近售价，盈利空间薄

改善建议：
1. 与供应商谈判阶梯采购返利，提升批量采购的额外收益；
2. 终端推广时搭配高毛利品种组合销售，拉高整体盈利水平。

### （三）低销量高毛利潜力品种
典型品种为齐鲁制药安立生坦片（单盒毛利 3.0 元）、以岭药业参松养心胶囊（单盒毛利 2.0 元）：
上述品种为专科 / 慢病用药，受众精准、毛利空间大，当前销量基数低，建议加大终端陈列支持、临床推广力度，提升动销规模。

### （四）量利双跌重灾区品种（预警）
典型品种为以岭药业连花清瘟胶囊、哈药集团双黄连口服液、云南白药蒲地蓝消炎片、修正药业斯达舒胶囊、石药集团阿奇霉素片：
上述品种销量同比大幅下滑，毛利额均低于 100 万元，建议：
1. 缩减后续采购量，优先消化现有库存；
2. 评估同品类替代供应商，若连续 3 个月动销未达阈值，启动淘汰流程。

## 四、风险提示
1. 无环比销售相关数据，暂无法识别环比同比双降品种
2. 本次统计范围内无毛利额低于 10 万元的品种 / 供应商
3. 同比下滑且毛利额低于 100 万元的高风险品种：哈药集团双黄连口服液（毛利 51.0 万元）、云南白药蒲地蓝消炎片（60.0 万元）、以岭药业连花清瘟胶囊（64.0 万元）、同仁堂感冒清热颗粒（80.0 万元）、石药集团阿奇霉素片（82.0 万元）、修正药业斯达舒胶囊（90.8 万元），需重点监控动销与库存。

## 五、下一步工作建议
1. 对金牛品种、爆发增长品种加大采购量，争取供应商年度返利、账期优惠政策
2. 对高风险品种、风险供应商执行采购额度管控，避免库存积压
3. 针对潜力品种制定专项动销方案，联合终端开展推广活动，释放盈利空间
4. 每半月跟踪重灾区品种动销情况，及时调整采购策略
