# AI‑demo‑portfolio‑new
> 📚 AI产品助理转行个人作品集，一共3个独立项目，覆盖 **API调用、RAG知识库智能体、业务自动化工作流**，完整落地于低代码/代码平台，全部附带可在线演示链接。

## 📋 项目总览
### 1. 智谱大模型网页生成工具（API‑Demo）
**在线体验：**[https://ai-demo-portfolio-pbqg3fhwtuhzyeu6vumbas.streamlit.app/]
- 技术栈：Python + Streamlit + 智谱GLM API
- 简介：一个对话式网页生成Demo。用户用自然语言提出需求，大模型自动输出可直接运行的HTML网页；支持多轮迭代修改、会话记忆、异常捕获，适合快速生成简历、活动落地页等静态页面。
- **能力验证：**大模型API对接、前端交互产品设计、异常容错方案设计。

### 2. 采购知识助手｜RAG知识库智能体（procurement‑rag‑bot）
**在线体验：**[https://www.coze.cn/store/agent/7694122642001051688?bot_id=true]
- 技术栈：扣子Coze、RAG知识库、提示词工程
- 简介：面向医药采购业务场景搭建私有知识库问答智能体。把采购规范、供应商准入、合同条款等内部文档入库，实现私有文档检索、条款查询、文档摘要、结构化信息提取；通过角色设定、Few‑shot、CoT、输出约束抑制大模型幻觉。
- **能力验证：**RAG智能体全流程产品设计、知识库分片调优、提示词工程、业务需求转化为AI产品方案。

### 3. 医药零售月度动销分析工作流（procurement‑monthly‑report‑workflow）
**在线体验：**[https://www.coze.cn/s/yQzakAfsRx4/]
- 技术栈：扣子Coze工作流、循环/分支组件、变量调度、LLM解耦
- 简介：医药采购月报自动化生成工作台，解决人工处理多维度销售数据、撰写分析报告效率低、大模型直接算数据容易产生算术幻觉的痛点。采用「数据录入‑AI初稿‑人工审核‑迭代修订」闭环工作流，拆分节点规避计算幻觉，输出标准化采购分析月报。
- **能力验证：**AI业务工作流拆解、分支与循环流程设计、业务痛点识别、多轮迭代产品方案落地。
